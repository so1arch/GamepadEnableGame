 GamepadEnableGame

Небольшая программа для Windows: **включаешь джойстик — автоматически запускается выбранная игра.**

Работает с геймпадами PS4 / PS5, Xbox и обычными USB- и Bluetooth-джойстиками. Тестировалась с GPS13B (клон PS4-геймпада).

## Возможности

- Выбор игры одной кнопкой: просто указываешь путь к `.exe`
- Игра запускается в момент, когда джойстик подключился (по USB или Bluetooth)
- Живёт в системном трее, окно не мешает
- Автозапуск вместе с Windows (стартует сразу в трей)
- Настраиваемая задержка перед запуском
- Защита от двойного запуска: если игра уже открыта, повторно она не стартует
- Кнопка тестового запуска игры
- Один `.exe` без установки, .NET ставить не нужно

## Как это работает

Программа раз в секунду проверяет список игровых устройств Windows (тот же, что показывает `joy.cpl`). Когда список из пустого становится непустым, то есть джойстик появился, она запускает выбранный `.exe`.

## Скачать готовую программу (сборка через GitHub Actions)

1. Открой вкладку **Actions** в этом репозитории.
2. Выбери последний успешный запуск **Build** (с зелёной галочкой).
3. Внизу, в разделе **Artifacts**, скачай `GamepadLauncher`.
4. Распакуй архив: внутри будет `GamepadLauncher.exe`.

> Если запусков нет, нажми **Build → Run workflow**. Сборка занимает 2–3 минуты.

Windows SmartScreen может показать предупреждение, потому что файл не подписан. Нажми **Подробнее → Выполнить в любом случае**.

## Использование

1. Положи `GamepadLauncher.exe` в постоянную папку, например `C:\Programs\GamepadEnableGame`. Если потом переместишь файл, автозапуск с Windows перестанет работать.
2. Запусти программу.
3. Нажми **Выбрать…** и укажи `.exe` игры.
4. Проверь кнопкой **Запустить игру сейчас (тест)**.
5. Закрой окно: программа продолжит работать в трее.
6. Включи джойстик, и игра запустится.

Выйти из программы полностью: правый клик по значку в трее → **Выход**.
